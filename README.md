# NOVA — эмулятор кредитного договора v.2

## Загрузка в GitHub
1. Распакуйте NOVA-Vercel.zip на компьютере.
2. Создайте новый репозиторий nova-emulator в GitHub.
3. Нажмите Add file → Upload files.
4. Загрузите ВСЕ файлы из архива в корень репозитория, без дополнительной папки.
5. Нажмите Commit changes.

## Публикация в Vercel
1. Откройте Vercel и нажмите Add New → Project.
2. Выберите репозиторий nova-emulator и нажмите Import.
3. Framework Preset: Other.
4. Root Directory: оставьте корень репозитория.
5. Build Command: оставьте пустым. Install Command: оставьте пустым.
6. Output Directory: . (точка).
7. Нажмите Deploy.

Файл vercel.json уже содержит настройки статического сайта.
После публикации изменения в GitHub автоматически обновляют сайт в Vercel.
Обычная ссылка Vercel доступна другим людям; доступ регулируется настройками проекта.

## Использование
Откройте сайт и выберите сценарий. Добавляйте расходы и погашения, переходите по дням и смотрите показатели договора. Кнопка «Режим презентации» увеличивает ключевые цифры и пояснения.
Можно также открыть index.html прямо на компьютере без интернета.
Операции сохраняются только до перезагрузки страницы.

## Модель
Основа: NovaCard_07072025(01).xlsm, лист NovaCard v.2 и макрос NavaCard_v2.
Проверены 7290 значений за 270 дней — совпадают с исходным примером Excel.
Периоды по 30 дней, ставки по умолчанию 24% и 36%, лимит 10000 AZN.
Сохранены особенности порядка расчётов макроса; подробности указаны внизу сайта.
Модель не учитывает время операций, выходные и задержки клиринга.
Перед обучением сотрудников проверьте актуальные условия NOVA.
